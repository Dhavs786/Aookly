System Architecture & Mathematical Formulation

1. Content-Aware Feature Extraction

Extracts ITU-T P.910 Spatial Information (SI) using Sobel gradients, Temporal Information (TI) across consecutive frames, Shannon color entropy, and dense optical flow vectors.

2. Pure-NumPy Random Forest ML Model

Multi-Output Decision Forest predicts Pareto-optimal quantizers (CRF 18–36, WebP Q 45–92), GOP intervals, and adaptive quantization strengths without external DLL dependencies.

3. Closed-Loop Feedback Auto-Tuning

Evaluates multi-channel Structural Similarity (SSIM) and Peak Signal-to-Noise Ratio (PSNR) post-encode. If visual quality drops below SLA, parameters are dynamically refined.
